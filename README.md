# Монитор Kleinanzeigen

Сканер новых объявлений [kleinanzeigen.de](https://www.kleinanzeigen.de) по всем категориям
с авто-публикацией живого среза на статический хостинг **here.now**.

**Сайт:** https://centered-birch-dbfv.here.now/

- 🔎 все категории, цикл сканирования ~60 с
- 👁 просмотры объявлений (приоритет — столбцам доски и «горячим» объявлениям)
- 🔥 фильтр «Горячие»: возраст 20+ минут и 10+ просмотров, iPhone-лоты скрыты
- 🧱 доска совпадений по категориям
- ⚡ живая страница: данные подтягиваются без перезагрузки, мобильная версия

Как это устроено и как развернуть — в [DEPLOY.md](DEPLOY.md).

**Зависимостей нет** — только стандартная библиотека Python 3.10+.
